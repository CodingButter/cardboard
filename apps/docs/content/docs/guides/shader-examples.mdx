The default pack ships two reference shader demos. Both use
Mode 3 (shader hooks) and weigh in under twenty lines of GLSL.
Source files live at
`packages/default-pack/shaders/`.

Read [Custom shaders](/docs/guides/shaders) for the mental model
and [the hook catalog](/docs/guides/shader-hooks-catalog) for the
reference. This page shows the demos end-to-end.

## Example 1 — Wet floor

A four-line override that forces every floor cell to behave like
a flooded mirror. The classic motivating case for Mode 3.

> _Screenshot placeholder — drop a wet-floor capture here when one
> is taken._

### Manifest

```jsonc
{
  "name": "shiny-floors",
  "version": "0.1.0",
  "engine": "two_5_d@0.1",
  "requires": [{ "id": "default", "version": "^0.2.0" }],
  "shaders": {
    "worldHooks": "shaders/wet-world-hooks.glsl"
  }
}
```

### Source

`packages/default-pack/shaders/wet-world-hooks.glsl`:

```glsl
// R4/S3 smoke test — Mode 3 hooks proof-of-life.
//
// Forces every floor cell to 85% mirror regardless of its authored
// reflectivity. We override-not-amplify because default-pack scenes
// have no authored reflection (`cellRefl.r == 0` everywhere), so the
// plan doc's `base * 4.0` example is a no-op here visually. A modder
// amplifying real authored reflectivity would write
// `clamp(base * 4.0, 0.0, 0.95)` instead.
//
// Surface enum (§7.1): 0 = floor, 1 = ceiling, 2 = wall.

float hook_modifyReflectivity(float base, vec2 cellCoord, int surface) {
  if (surface == 0) return 0.85;
  return base;
}
```

### Walkthrough

The engine computes a per-pixel reflectivity scalar `base` that
mixes the surface color with a reflection sample. By default
that scalar is read from the lightmap-bake reflection channel
the level designer authored — `cellRefl.r` for floors,
`cellRefl.b` for ceilings.

For default-pack scenes that channel is zero everywhere, so the
plan doc's "amplify by 4×" idiom would still produce zero.
Instead we force a literal `0.85` for every floor pixel, which
flips the entire pack into a wet-corridor look without touching
walls, ceilings, or caps.

### The amplify variant

For scenes that authored their own reflective cells (e.g. only
specific tiles are marked shiny), prefer the amplify pattern so
dry cells stay dry:

```glsl
float hook_modifyReflectivity(float base, vec2 cellCoord, int surface) {
  if (surface == 0) return clamp(base * 4.0, 0.0, 0.95);
  return base;
}
```

The `clamp` to 0.95 keeps the reflection from blowing out to a
fully opaque mirror.

## Example 2 — Night vision + vignette + sprite glow

A single source file referenced from **both** `worldHooks` and
`spriteHooks` in the manifest. Phosphor-green NVG everywhere,
plus an aspect-corrected circular vignette, plus a per-sprite
glow boost in the dark zones of the screen.

> _Screenshot placeholder — drop a night-vision capture here when
> one is taken._

### Manifest

```jsonc
{
  "name": "night-vision",
  "version": "0.1.0",
  "engine": "two_5_d@0.1",
  "requires": [{ "id": "default", "version": "^0.2.0" }],
  "shaders": {
    "worldHooks":  "shaders/night-vision.glsl",
    "spriteHooks": "shaders/night-vision.glsl"
  }
}
```

The same file is loaded twice — once for each role. The S3 hook
parser only extracts functions starting with `hook_`, and each
role only accepts the hooks valid for its role. So
`hook_modifyFinalColor` is wired into the world program;
`hook_modifySpriteFinalColor` is wired into the sprite program.
The remaining text in the file is ignored per role.

### Source

`packages/default-pack/shaders/night-vision.glsl`:

```glsl
// R4/S3 demo — phosphor-green night vision goggles + circular
// vignette so it reads as "looking through optics."
//
// Two effects per pixel:
//   1. Luminance + green tint  (classic NVG phosphor look).
//   2. Screen-space vignette   (aspect-corrected circular falloff).
//
// Applied to BOTH world surfaces (walls / floors / ceiling) AND
// sprites (items, projectiles, pickups). The world and sprite
// fragment shaders are separate WebGL programs with their own hook
// preludes, so the effect needs two hooks — one per role. Same math
// both times. Manifest references this file from BOTH `worldHooks`
// and `spriteHooks` so both shaders get patched.
//
// Note: the S3 hook parser only extracts functions named `hook_*`.
// Helpers defined in this file would not be carried into the
// compiled shader (no `#include` yet — deferred S3 work). So the
// math is inlined twice rather than factored into a shared helper.
//
// Surface enum for world (§7.1): 0 = floor, 1 = ceiling, 2 = wall.

// Walls / floors / ceiling.
vec3 hook_modifyFinalColor(vec3 base, vec2 worldPos, int surface) {
  // Phosphor-green NVG.
  float luminance = dot(base, vec3(0.299, 0.587, 0.114));
  float boosted = clamp(luminance * 1.6 + 0.05, 0.0, 1.0);
  vec3 phosphor = vec3(boosted * 0.15, boosted, boosted * 0.15);

  // Aspect-corrected circular vignette.
  vec2 screenUv = gl_FragCoord.xy / u_resolution.xy;
  vec2 fromCenter = screenUv - vec2(0.5);
  fromCenter.x *= u_resolution.x / u_resolution.y;
  float v = smoothstep(0.55, 0.22, length(fromCenter));

  return phosphor * v;
}

// Sprites (items, pickups, projectiles).
//
// Sprites do NOT get vignette darkening — they stay at full brightness
// regardless of screen position. On top of that, we *boost* their
// intensity in the vignette's dark zones, so items at the edge of
// the screen appear to glow against the darkened backdrop. Classic
// "thermal blob through NVG" read.
vec3 hook_modifySpriteFinalColor(vec3 base, int layer, vec2 worldPos) {
  // Phosphor-green NVG.
  float luminance = dot(base, vec3(0.299, 0.587, 0.114));
  float boosted = clamp(luminance * 1.6 + 0.05, 0.0, 1.0);
  vec3 phosphor = vec3(boosted * 0.15, boosted, boosted * 0.15);

  // Same aspect-corrected vignette math as the world hook.
  vec2 screenUv = gl_FragCoord.xy / u_resolution.xy;
  vec2 fromCenter = screenUv - vec2(0.5);
  fromCenter.x *= u_resolution.x / u_resolution.y;
  float v = smoothstep(0.55, 0.22, length(fromCenter));

  // Darkness ramp inverts the vignette: 0 at center, 1 at corner.
  // Quadratic curve so the glow only kicks in near the edge.
  float darkness = 1.0 - v;
  float glow = 1.0 + darkness * darkness * 1.5;

  return phosphor * glow;
}
```

### Walkthrough

The shader runs four logical steps per pixel:

1. **Luminance.** Standard Rec. 601 weights collapse the engine's
   final color into a single brightness value, then boost it
   (`1.6` gain plus a `0.05` floor so deep shadow doesn't go
   completely black).

2. **Phosphor tint.** The boosted luminance modulates a pure
   green channel with a touch of red and blue (`0.15`) so it
   reads as monochrome-tinted rather than pure neon.

3. **Vignette.** Convert `gl_FragCoord` to a centered screen UV,
   correct for aspect ratio (otherwise widescreens get an
   ellipse), and `smoothstep` from center to edge. The two
   constants (`0.55` outer, `0.22` inner) control how wide the
   bright zone is and how soft the falloff is.

4. **Sprite glow.** For the sprite hook, invert the vignette to
   get a darkness ramp, square it for a quadratic ramp, then
   scale the sprite up to `2.5×` brightness at the corners.
   Items at the screen edge appear to glow against the darkened
   backdrop — the "thermal blob through NVG" read.

### Hook-only is the right call here

Both effects could be implemented as a Mode 1 full role
replacement, but you'd be writing the engine's forward-shading
pipeline by hand to do it. Mode 3 lets you reuse the engine's
lighting, reflections, AO, and fog work — your hook only runs on
the final composited color.

### Engine intrinsics inside hooks

The example relies on two things that aren't obvious from the
hook signature:

- **`gl_FragCoord`** — always available inside any fragment
  shader.
- **`u_resolution`** — declared by the auto-injected header for
  every role, so it's in scope inside any hook body.

The full uniform contract per role lives in
`docs/plans/ENGINE_PACK_SHADERS.md` §6. The short version: any
uniform documented for the role is available inside any hook
running in that role.

## Cool things to try

A non-exhaustive list of effects that drop out of small hook
combinations. Most are one-or-two-hook patches over the engine
default; rough sketches included.

### Sepia tone

One final-composite hook, one matrix multiply. Drop it into the
world shader and the whole game looks like a photograph from
1910.

```glsl
vec3 hook_modifyFinalColor(vec3 base, vec2 worldPos, int surface) {
  float l = dot(base, vec3(0.299, 0.587, 0.114));
  return vec3(l) * vec3(1.07, 0.74, 0.43);
}
```

### Cel-shading

Quantize luminance into N bands. Posterise lighting; the world
reads like a hand-painted cartoon.

```glsl
vec3 hook_modifyFinalColor(vec3 base, vec2 worldPos, int surface) {
  float l = dot(base, vec3(0.299, 0.587, 0.114));
  float bands = floor(l * 4.0 + 0.5) / 4.0;
  return base * (bands / max(l, 0.001));
}
```

### Stained glass

Per-tile tint on walls only; uses `tile` to pick a palette
without needing per-cell metadata.

```glsl
vec3 hook_modifyAlbedo(vec3 base, vec2 uv, int tile, int surface) {
  if (surface != 2) return base;
  vec3 tints[3] = vec3[3](
    vec3(1.0, 0.4, 0.4),
    vec3(0.4, 1.0, 0.5),
    vec3(0.4, 0.5, 1.0)
  );
  return base * tints[tile % 3];
}
```

### Lava fog

Heat-shimmer recolour: replace the default no-op fog color with
a bright orange and let depth do the work.

```glsl
vec3 hook_modifyFogColor(vec3 base, float depth) {
  return mix(vec3(0), vec3(1.2, 0.4, 0.1), smoothstep(2.0, 12.0, depth));
}
```

### Sunset sky

Soft horizon + warm tint at the bottom. Two of the three sky
hooks.

```glsl
vec3 hook_modifySkyBottom(vec3 base, vec2 uv) {
  return mix(vec3(1.0, 0.5, 0.2), base, uv.y * 2.0);
}
float hook_modifySkyGradient(float base, vec2 uv) {
  return smoothstep(0.40, 0.58, uv.y);
}
```

### Pulse-glow emissive

Animate the emissive add with `u_time` for a slow heartbeat over
already-emissive surfaces.

```glsl
vec3 hook_modifyEmissive(vec3 base, int surface, vec2 worldPos) {
  float pulse = 0.5 + 0.5 * sin(u_time * 2.0);
  return base * (0.8 + 0.4 * pulse);
}
```

---

Stack any combination — hooks compose because each one only
touches the intermediate it names. A wet-floor reflectivity
override plus a sepia final-color plus a soft horizon all
coexist in one `world-hooks.glsl` / `sky-hooks.glsl` pair
without further coordination.

When you outgrow what hooks can do — for example you want neon
wireframe walls that need actual edge detection across
neighbouring cells, or PSX vertex jitter that needs vertex-shader
control — graduate to Mode 1 role replacement. See
`docs/plans/ENGINE_PACK_SHADERS.md` §13.2 for the neon-wireframe
sketch.

---
title: cardboard
description: A browser-based 2.5D raycaster engine where every game ships as a hot-loadable asset pack.
---

cardboard is a Wolfenstein-style raycaster written in TypeScript + Bun,
rendered to canvas2d or WebGL2. The engine knows nothing about the game
it's running — every game ships as a single `.apg` asset pack that the
runner loads on demand.
